# SoundCloud Download Helper

SoundCloudの入手候補を緑枠で見つけ、ダウンロードした音声に曲名やジャケットを書き込むChrome / Edge用拡張機能です。Manifest V3、バージョン **1.19.16**。

## できること

- 検索結果・アーティストの個人ページ・曲ページのDownload / Buy / Free表示を検出し、緑枠で強調します。
- 一覧右上の「5/10」のような件数を押すと、候補だけの表示に切り替えます。
- 拡張機能アイコンで、最初から絞り込む設定と約50曲の自動読み込みを切り替えます。初期値はどちらもオフです。
- SoundCloud標準のダウンロードと、SoundCloudから開いた外部配布サイトでのダウンロードを関連付け、曲名・アーティスト・ジャケットなどを書き込みます。
- MP3 / WAV / FLAC、同じ曲の音声をまとめたZIPに対応します。通常版とExtended版を区別します。
- 判定キャッシュをJSONで書き出し、別のPCへ移せます。

ボカロ記録用の拡張機能は不要です。このリポジトリだけで強調・追跡・タグ書き込みが動きます。

## インストール

1. GitHubの「Code → Download ZIP」で取得し、展開します。
2. Chromeで `chrome://extensions`、Edgeで `edge://extensions` を開きます。
3. デベロッパーモードをオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` があるフォルダーを選びます。
5. 開いているSoundCloudを再読み込みします。

ビルド・Node.js・外部サーバーは不要です。更新時も拡張機能とSoundCloudの両方を再読み込みしてください。

## 自動タグ付けの設定

1. ブラウザーの通常のダウンロード先に `SoundCloud` フォルダーを作ります。
2. 拡張機能アイコンから「自動タグ付けの設定」を開きます。
3. 必要な権限を許可し、その `SoundCloud` フォルダーを選んで読み書きを許可します。
4. 設定完了を確認し、SoundCloudを再読み込みします。
5. 曲のDownloadボタン、または曲にある配布リンクからダウンロードします。

設定時だけ小さな確認ファイルを保存し、選択したフォルダーと保存先が一致することを確認して削除します。フォルダー名を変える場合は設定画面の相対パスも合わせてください。保存場所を毎回選ぶ設定なら、対象ファイルは許可したフォルダーに保存してください。

対象ファイルを専用フォルダーへ保存した後でタグを書き込みます。SoundCloudの曲名でファイル名とタイトルを揃え、ほかの対象タグは空欄を補います。既存のジャケットと音声データは保持します。結果は拡張機能アイコンで確認できます。自動タグ付けは設定画面からオフにできます。

SoundCloud標準の操作領域には、明示的に取得してタグを書く「タグ付きで保存」ボタンも追加します。このボタンを押した場合のみ、ページのログイン状態を使ってダウンロードAPIにアクセスします。

## 配布サイトの追跡

Hypeddit・ToneDen・Dropbox・Google Drive・Bandcampなど、SoundCloudから実際にたどった配布先とファイルの情報を照合します。サイト名だけで対象にしたり、「直前に見た曲」やファイル名だけから推測したりしません。

Google Driveは確認できたファイルID、Bandcampはダウンロード画面と配信ファイルの曲IDも使います。対応が一意でない、情報が足りない、有効期限が切れた場合は通常保存のままです。すべてのサイト・遷移経路での検出を保証するものではありません。配布サイトのログイン・フォロー・購入などは通常どおり行ってください。

自動タグ付けは通常のダウンロード完了後に行い、音声を再取得しません。ジャケットが不足する場合はSoundCloudの画像CDNから取得します。

## 判定と制限

- Buyやタイトル中のFreeも候補です。無料・現在の入手成功を保証する表示ではありません。
- SoundCloud標準ダウンロードの上限到達が分かっている曲は除外します。ただし別の配布リンクがあれば候補に残します。
- 既存のページデータを優先し、不足時の公開HTML確認は全タブ合計で同時1件・4秒以上の間隔・毎時60件までです。403 / 429時は最低30分停止します。
- 約50曲の読み込みは全曲数に対するものです。候補50曲を集める機能ではありません。処理回数・待機時間にも上限があります。
- ZIPは同一曲の各形式と通常版 / Extended Mix・Edit・Version等に対応します。別曲の混在、暗号化、ZIP64、未対応の圧縮・文字コード、破損、展開後256MB超では書き換えません。PCへの自動展開はしません。
- タグ処理の失敗時は元のファイルを保持します。書き換え後のZIPはサイズが増える場合があります。
- SoundCloudや配布サイトの仕様変更により、検出できなくなる場合があります。

## 別のPCへの移行

本体フォルダーをコピーするか、このリポジトリから取得して新しいPCへ読み込みます。判定キャッシュが必要なら、旧PCの拡張機能アイコンで「判定データを書き出す」、新PCで「判定データを読み込む」を使います。有効期限は延長しません。

自動タグ付けのフォルダー許可はPCごとに設定してください。設定・閲覧履歴・追跡セッション・ダウンロードした音源はこのリポジトリには含まれません。

## 開発

実行時の外部ライブラリ依存はありません。Node.js 22以降で `npm test` を実行すると、公開用に含めたキャッシュ移行・通信制限の回帰テストが動きます。テストは通信やログイン済みブラウザーを使いません。

既存開発環境では、独立したEdgeと生成音声を使った追跡・タグ・ジャケット・デコード後音声一致の検証も行っています。このリポジトリに含むテストはその一部であり、実サイトへのログイン後の配布手続きを自動検証するものではありません。

個人のブラウザープロファイル・履歴・音源・取得したページHTML・診断ログはコミットしないでください。詳しくは [プライバシー](PRIVACY.md) と [参考情報](NOTICE.md) を参照してください。

SoundCloud公式の拡張機能ではありません。
